# 🎬 Reels & Short Video Downloader Telegram Bot (@igwpbot)

Instagram, Facebook, YouTube Shorts, ShareChat എന്നിവയിൽ നിന്നുള്ള റീലുകളും വീഡിയോകളും വളരെ വേഗത്തിൽ ഡൗൺലോഡ് ചെയ്യുന്നതിനും, അവയെ MP3 ഓഡിയോ ആയി മാറ്റുന്നതിനും വേണ്ടിയുള്ള ടെലിഗ്രാം ബോട്ട്.

---

## ✨ സവിശേഷതകൾ (Key Features)

1. **മൾട്ടി-പ്ലാറ്റ്‌ഫോം പിന്തുണ (Multi-Platform Support):**
   - 📸 **Instagram:** Reels, Posts, IGTV
   - 🔴 **YouTube:** Shorts, Videos
   - 🔵 **Facebook:** Reels, Watch, Public Videos
   - 💬 **ShareChat:** Reels, Videos
2. **ഡിഫോൾട്ട് വീഡിയോ ഡൗൺലോഡ് (Default Video Download):**
   - ലിങ്ക് അയച്ചാൽ ഉടൻ തന്നെ ഏറ്റവും ഉയർന്ന നിലവാരത്തിലുള്ള MP4 വീഡിയോ ഡൗൺലോഡ് ചെയ്ത് അയക്കുന്നു.
3. **MP3 ഓഡിയോ ഓപ്ഷൻ (Audio MP3 Option):**
   - വീഡിയോ സന്ദേശത്തോടൊപ്പം `🎵 MP3 ഓഡിയോ ഡൗൺലോഡ് ചെയ്യുക` എന്ന Inline Button ലഭ്യമാണ്. ഒരു ക്ലിക്കിൽ വീഡിയോയെ MP3 ആക്കി അയച്ചു തരും.
   - കൂടാതെ `/audio <ലിങ്ക്>` അല്ലെങ്കിൽ `/mp3 <ലിങ്ക്>` കമാൻഡ് വഴി നേരിട്ട് ഓഡിയോ മാത്രം ഡൗൺലോഡ് ചെയ്യാം.
4. **സ്മാർട്ട് സൈസ് ഒപ്റ്റിമൈസേഷൻ (Smart Size & Compression):**
   - ടെലിഗ്രാമിന്റെ 50MB പരിധി കവിയുന്ന വലിയ വീഡിയോകൾ ഓട്ടോമാറ്റിക്കായി FFmpeg വഴി കംപ്രസ് ചെയ്യപ്പെടുന്നു.
5. **മലയാളം ഇന്റർഫേസ് (Malayalam Interface):**
   - ബോട്ടിലെ എല്ലാ നിർദ്ദേശങ്ങളും സന്ദേശങ്ങളും മലയാളത്തിലാണ് സജ്ജീകരിച്ചിരിക്കുന്നത്.

## 🚀 ഇൻസ്റ്റാളേഷനും റൺ ചെയ്യലും (Setup & Run)

### 1. മുൻവ്യവസ്ഥകൾ (Prerequisites)
- Python 3.10+
- FFmpeg (സിസ്റ്റത്തിൽ ഇൻസ്റ്റാൾ ചെയ്തിട്ടുണ്ടെന്ന് ഉറപ്പുവരുത്തുക)

### 2. .env ഫയൽ കോൺഫിഗറേഷൻ
`.env` ഫയൽ നിലവിൽ സജ്ജീകരിച്ചിട്ടുണ്ട്:
```env
BOT_TOKEN=8875302580:AAGmKwekGBFZuK0wp9rRS_3e-k7V6sxJqGY
ADMIN_ID=856833667
DOWNLOAD_DIR=downloads
MAX_FILESIZE_MB=50
```

### 3. ബോട്ട് റൺ ചെയ്യുക
```bash
./run.sh
```
അല്ലെങ്കിൽ:
```bash
./venv/bin/python3 bot.py
```

## 💡 ബോട്ട് കമാൻഡുകൾ (Bot Commands)

- `/start` - ബോട്ട് ആരംഭിക്കാനും സ്വാഗത സന്ദേശം കാണാനും.
- `/help` - സഹായവും ഉപയോഗക്രമങ്ങളും.
- `/audio <ലിങ്ക്>` അല്ലെങ്കിൽ `/mp3 <ലിങ്ക്>` - വീഡിയോയ്ക്ക് പകരം നേരിട്ട് MP3 ഓഡിയോ ഡൗൺലോഡ് ചെയ്യാൻ.
